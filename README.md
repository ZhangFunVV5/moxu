# 「墨序 MOXU」AI 书籍综合工作台

面向长篇小说与书籍稿件的桌面工作台，将原稿导入、正文编辑、AI 精校、标题与摘要生成、排版导出收束在同一条工作流里，让写作者与编辑在同一处完成从原稿到成稿的全部处理。

## 导入与分章

- 支持导入 TXT 与 Markdown 书稿，自动识别 UTF-8、带 BOM、UTF-16、GB18030、Big5 等常见编码；编码存在歧义或出现替换字符时，要求手动确认后再继续。
- 导入前提供分章预览，不写入磁盘；可调整后再确认入库。
- 自动识别中文章号、回／节、卷、序章、尾声、番外等章节结构，代码围栏内的标题不会被误判为章节。
- 支持整篇作为一章、合并相邻章节、逐章修改章名。

## 正文编辑与本地工作区

- 每本书建立独立工作区，章节标题与正文分离存放，原稿另存副本，修改不覆盖原始文件。
- 内置编辑器支持单章正文编辑、未保存标记与快捷键保存；修订号不一致时拒绝覆盖，避免并发修改丢失内容。
- 章节、工作区切换以及导入、关闭前均有未保存保护，可选择保存、放弃或取消。
- 工作区、章节与编辑记录全部保存在本地，可随时关闭并重新打开继续。

## AI 精校

- 按当前章、勾选章节或全书发起精校，可选错字、用词、语法、广告等检查类别，并配置专名词表与额外要求。
- 除表单设置外，也可用自然语言描述精校要求，两种入口共用同一套检查范围与选项。
- 意见逐条呈现，可采纳、忽略、定位原文；已采纳意见支持逐条撤回，已忽略意见可恢复待审。
- 提供修改对照视图，区分已采纳与待审修改；删除类修改以独立锚点标记，不写入正文。
- 支持自动应用已授权的修改类别，默认关闭；正文发生手工编辑或批次外修改时，旧意见标记为过期并保留只读查看。
- 可导出精校报告，记录最终有效修改、未生效意见与审阅操作。
- 任务中断或关闭后可从已保存进度继续，已完成的检查块不重复执行。

## 排版与导出

- 按当前章、勾选范围或全书排版，支持 TXT 与 Markdown 两种输出。
- 可设置标题模板、首行缩进、段落识别方式、段间空行、行尾空白清理、换行符与 UTF-8 BOM。
- 排版结果实时预览，确认后在系统对话框中另存导出；排版只生成输出文件，不改写工作正文。
- 支持把常用排版参数保存为预设，下次打开直接复用。
- 也可用自然语言描述排版规则，生成候选设置，采纳后才应用到表单。
- Markdown 输出保留标题、段落、列表、代码、引用与链接等原有结构。

## 标题与摘要

- 针对当前章、选定章节或全书生成章节标题候选，可设置长度、风格与是否允许剧透；候选可编辑后再选用，也可保留原标题。
- 标题选择只更新章节标题与目录，不改写正文。
- 生成章节摘要，支持调整摘要长度，结果独立保存，不插入小说正文，可按范围单独导出。
- 长章自动分段提取要点再汇总，避免一次输入过长导致结果失真。
- 每项生成结果记录来源正文版本，正文变化后旧结果标记为过期，仍可查看但不会误用。

## 组合流程

- 可将精校、审阅、标题生成、摘要生成、排版与导出编排为一条组合流程，按固定顺序自动推进。
- 精校意见需要人工确认时流程暂停，审阅完成后从最新正文继续后续阶段。
- 独立排版与导出不依赖模型，可在不配置模型的情况下单独使用。
- 流程中断后可继续未完成阶段，已完成阶段不会重复执行。

## 模型接入

- 支持兼容 Chat Completions 协议的服务，可配置 Base URL、模型名称与 API Key。
- API Key 在本地加密保存，界面只显示是否已配置，不以明文回显。
- 模型配置在任务启动时快照，运行中的任务不受后续设置修改影响。
- 所有 AI 能力均在用户明确发起后执行，生成结果需人工确认才会写入正文或标题。
